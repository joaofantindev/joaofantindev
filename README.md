## Engineering Mindset

I believe good software engineering goes beyond knowing programming languages.

It's about understanding the entire environment where software lives:

- **Architecture:** Designing systems that are maintainable and scalable.
- **Performance:** Understanding bottlenecks and optimizing where it matters.
- **Security:** Building with security in mind from the beginning.
- **Infrastructure:** Understanding deployment, containers, networking, and Linux.
- **Automation:** Eliminating repetitive work through intelligent tooling.

My goal is to become a well-rounded engineer capable of working across the entire software lifecycle.
